CARA MAIN
🃏 DASAR
52 kartu dibagi rata. Habiskan kartu pertama = menang.
Urutan: 3 < 4 < 5 … 10 < J < Q < K < A < 2
🟢 FASE PEMBUKAAN
Pemegang 3♠ wajib keluarkan itu. Pemain lain boleh buang kartu 3 atau skip. Serentak, tidak bergilir.
⚠️ KARTU SPESIAL
Kartu 3 = Pengecoh — buang kapan saja, giliran tidak pindah
Kartu 2 = Terkuat, tapi:
 • Sisa 2 kartu efektif + ada 2 → WAJIB main 2 dulu
 • Sisa hanya kartu 2 → LANGSUNG KALAH
🎯 KOMBINASI
Single
1 kartu
Double
2 kartu nilai sama
Triple
3 kartu nilai sama
Straight 3+
3+ berurutan, 1 jenis (angka / huruf saja)
Bomb 4 💣
4 nilai sama — kalahkan kartu 2!
JQKA 👑
J+Q+K+A 1 jenis — bomb tertinggi!
💥 EFEK KHUSUS
• Bomb4/JQKA mengalahkan kartu 2 tunggal
• Straight4 men-STOP pemain sebelumnya 1 giliran
• Semua skip → meja reset, pemain terakhir bebas main

1. HP host aktifkan Hotspot
2. HP lain connect ke hotspot tersebut
3. Host jalankan: node server.js di Termux
4. Bagikan IP yang muncul ke teman
5. Teman buka IP di browser
